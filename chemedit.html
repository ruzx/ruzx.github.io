Introduction

ChemEdit is an Electronic Lab Notebook (ELN) and chemical drawing plugin for Obsidian. It provides tools for synthetic chemists to draw molecules, calculate stoichiometry, track inventory, and map synthesis pathways entirely offline within their local vault.

Installation

ChemEdit is available in the official Obsidian Community Plugins directory.

  1. Open Obsidian Settings -> Community Plugins.
  2. Click "Browse" and search for ChemEdit.
  3. Or, click this direct link: Install ChemEdit.
  4. Click Install, then Enable.

Drawing Molecules

ChemEdit embeds Ketcher, allowing you to draw chemical structures natively inside Obsidian.

  • New Drawing: Click the Hexagon icon in the left ribbon to open the canvas.
  • Supported Formats: The plugin supports saving as SMILES, .mol, .cdxml, and .ket.
  • Editing: Double-click any rendered chemical structure in your notes to re-open the editor.

Inline Structures

Molecules can be rendered directly inside text or Markdown tables. Use the prefix $smiles= followed by your SMILES string.

The reaction yielded $smiles=CC(=O)OC1=CC=CC=C1C(=O)O as a solid.

The ELN Block

To record a reaction, open the Command Palette (Ctrl+P), select ChemEdit: Open ELN Dashboard, and click + New Experiment. This creates a YAML block:

```eln
status: Planned
reactants:
  - smiles: "CC1=CC(=O)CCC1"
    eq: 1
    mass: 150
products:
  - smiles: "CC1=CC(O)CCC1"
```

Obsidian parses this block and renders a reaction scheme alongside a stoichiometry table.

Stoichiometry Engine

The ELN block calculates reaction values automatically:

  • Molecular Weights: Calculated offline using OpenChemLib or Ketcher's engine.
  • Calculations: Double-click table cells to input a mass. The mmols and theoretical yields calculate based on the limiting reagent (eq = 1).
  • Yields: Enter the isolated mass in the Products table to generate a percentage yield.

Inventory & Orders

By adding specific tags to your notes (e.g., tags: [inventory] or tags: [order]), the plugin aggregates them into central dashboards. Open these dashboards from the Command Palette to view your stock and active requests.

Synthesis Pathways

ChemEdit maps relationships between experiments based on their reactants and products.

Insert the code block ```synthesis-map``` in a note. The plugin will scan the folder and generate a flowchart of the project.

Web Sharing

To share a reaction with someone who does not use Obsidian, click the 🔗 Share button on the ELN block. This generates a URL containing the serialized stoichiometry data. The recipient can view the reaction and edit the equivalents in their browser.

You can test the web version here: ChemEdit Web ELN.
